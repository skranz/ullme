# uLLMe Agent Tools

A core design principle of uLLMe shall be that an AI agent can also help to use uLLMe and do tasks like customizing activities or creating object instance files based on the uploaded materials.

To do this the AI needs tools access, in particular to read or write files or get other information. On the other hand, for security reasons the AI should not have arbitraty access. E.g. all write operations must be limited to stuff the current user is allowed to edit.
