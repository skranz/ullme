Course materials

Materials are the source files that you organise for your course and make available to AI Tutors. Select a course before adding files.

Typical workflow

  1. Create folders that reflect how you teach the course, such as slides, problem sets, or background reading.
  2. Upload files or drag them into the material list.
  3. Select one or more files to move, copy, convert, or delete them.
  4. Open a text-based course file to inspect or edit it.

Material folders shows the teaching-oriented folder view. All course files also shows configuration and generated files.

Tip: Give files and folders clear names. This makes it easier to select the right documents when configuring a Tutor.
