Instance YAML

This is the structured source behind the Instances table. It is useful for reviewing or changing many assignments at once.

  • course_docs assigns documents shared by all Tutor instances.
  • instances contains each instance ID, student-facing label, and its document-role assignments.
  • Material paths are relative to the course's materials folder.

Preserve the indentation and expected field names, then choose Save instance YAML. Return to the Instances tab for the table view.

Be careful: Saving this text replaces the complete instance assignment file for this Tutor.
