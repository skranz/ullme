Test Suites

Test Suites run repeatable student inputs against one or more variants of a course AI Tutor. Create one from Add → New Test Suite.

  1. Add text and image inputs for the Tutor instances you want to exercise.
  2. Define YAML variants containing only the Tutor fields you want to override.
  3. Choose models and execution settings, then start a run.
  4. Inspect final answers and the output and duration of every workflow node.

A suite stores a snapshot of its source Tutor and instances. Later edits to the course Tutor therefore do not change the meaning of earlier test runs.
