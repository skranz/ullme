Tutor definition YAML

This is the complete course-local definition that controls the Tutor's identity, documents, prompts, tools, and workflow.

Workflow essentials

  • start_node names the first workflow node.
  • prompt calls the model, while next continues to another node.
  • switch_input and switch_to select a branch.
  • ask_for_input pauses and asks the student for more information.
  • A node without next or switch_to returns its output to the student.

YAML indentation is meaningful. Keep spaces and mapping levels consistent, then choose Save definition YAML. Invalid definitions are rejected rather than used.

Tip: Open the Flow diagram after saving to check that the routes express the teaching logic you intended.
