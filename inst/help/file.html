Course file editor

The file editor lets you inspect and change a text-based file from the selected course. The file name and its path are shown above the editor.

Working safely

  • Edit the content in the middle pane. You can press Ctrl+S (or Command+S on macOS) to save.
  • Use Save before going back or selecting another course.
  • If the file contains YAML or another structured format, preserve its indentation and punctuation.
  • Use the available history controls to compare with or restore a previous saved version.

If you do not understand a setting, open AI chat and ask about the current file before changing it.
