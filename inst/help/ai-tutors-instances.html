Instances

Consider a problem set tutor: each problem set of the course is a separate instance. Each instance is defined by the problem set file and a solution file.

First make sure you have uploaded all problem set files in the Materialpane. You can convert PDF or DOCX there to computer readable txt or md files, which we need.

  • Instance ID is an internal ID of the instance. Use a short ID without spaces or Umlaute such as ps1.
  • Label is the name students see also short like "ÜB1".
  • The remaining fields assign course materials to the document roles defined by the Tutor.

Use Add instance to create rows manually, or Make Instances to ask the AI helper to group matching files. Changes are saved automatically when you leave an edited text field. Adding or removing an assignment is also saved automatically; the status beside the buttons shows when saving is complete.

Course documents apply to every instance. Documents in an instance row apply only to that one activity.
