Tutor instances

An instance is one concrete activity offered by this Tutor—for example, one problem set, case, or group of related documents. Students choose an instance before starting the Tutor.

Assign the documents

  • Instance ID is the stable technical name. Use a short ID without spaces, such as ps1.
  • Label is the name students see.
  • The remaining fields assign course materials to the document roles defined by the Tutor.

Use Add instance to create rows manually, or Make Instances to ask the AI helper to group matching files. Review every generated assignment, then choose Save assignments.

Course documents apply to every instance. Documents in an instance row apply only to that one activity.
