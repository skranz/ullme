AI Tutors

An AI Tutor defines how the assistant should teach a particular topic or activity. Each Tutor belongs to the selected course.

Create and prepare a Tutor

  1. Choose Add → Add Tutor and select a starting template.
  2. Give the Tutor a clear name and description so students know when to use it.
  3. Configure its instructions, learning workflow, and course documents.
  4. Create Tutor instances when the activity needs separate exercises, cases, or problem sets.
  5. Save your changes and test the Tutor before sharing the course with students.

When you start an AI-assisted action such as making instances, this pane automatically opens AI chat so you can follow the work and answer questions.

Important: Review generated instructions and instances as teaching material. The AI can propose content, but you remain in control of what students receive.
