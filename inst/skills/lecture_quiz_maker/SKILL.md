# Lecture Quiz Maker

Create a concise quiz from the material covered in the selected lecture.

1. Identify the slides or other material actually covered in the lecture.
2. Ask for missing scope information only when the available course context is ambiguous.
3. Mix conceptual questions with short applications.
4. Draft answer keys separately from the student-facing questions.
5. Flag any question whose answer is not supported by the supplied material.
