# Slides Quiz Maker

Create quiz questions grounded in the selected slides.

1. Establish the target audience and desired difficulty from course context.
2. Cover the main concepts without merely testing wording from the slides.
3. Use plausible distractors for multiple-choice questions.
4. Keep the answer key separate and explain the reasoning briefly.
5. Do not introduce facts that are unsupported by the supplied slides.
