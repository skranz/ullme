# AI Tutors

AI Tutors are student-facing, course-local workflows. Teachers add a bundled
Tutor template to a course and then edit that course copy. Tutor definitions
control prompts, workflow nodes, permitted files, document roles, and whether
the Tutor uses multiple instances.

Instance assignments connect named document roles to files below the course's
`materials` directory. The Instance Builder is a fixed application helper: it
uses filenames and Tutor document-role metadata to propose complete YAML, which
the application validates before saving.
