# Materials and course organization

Materials are stored by course and category. Text files can be opened directly
in the teacher studio; binary files remain visible but are not edited as text.

Object-index YAML files describe pedagogical objects such as problem sets
(`ps`), their solutions (`ps_sol`), slides, lecture events, and scripts. They
record order, file formats, roles, and links. In particular, each solution
object should link to an existing problem-set object.

**Organize with AI** creates a proposal. It may classify only files that already
exist, must not invent paths, and must leave ambiguous files unassigned. uLLMe
validates the proposal before the teacher can apply it.
