# uLLMe teacher overview

uLLMe gives a teacher one workspace for course materials, their organization,
student-facing AI Tutors, reusable Skills, and the YAML or Markdown definitions
behind them.

A practical first workflow is:

1. Create or select a course.
2. Upload materials such as lecture notes, slides, problem sets, and solutions.
3. Open **Organize** and review the current structure. The AI can propose object
   indexes, but the teacher reviews the YAML before it is applied.
4. Add an AI Tutor to the course and inspect its definition and required
   material roles.
5. Use **Definitions** to create personal or course-local variants. Every YAML
   save is checked before it is written.
6. Use the AI assistant for explanations, inspection, organization proposals,
   and reviewable file changes.

The assistant can always be asked “What can I do next?” It should inspect only
the current teacher's project state and suggest the smallest useful next step.
