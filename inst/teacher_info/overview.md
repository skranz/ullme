# uLLMe teacher overview

uLLMe gives a teacher one workspace for course materials, student-facing AI
Tutors and the YAML definitions behind them.

A practical first workflow is:

1. Create or select a course.
2. Upload materials such as lecture notes, slides, problem sets, and solutions.
3. Add an AI Tutor to the course and review its required per-instance and
   per-course documents.
4. Review the suggested Tutor instances and correct their document assignments
   before saving them.
5. Edit the Tutor through its form or YAML tab. Every YAML save is checked
   before it is written.
6. Use the AI assistant for explanations, inspection, and reviewable changes.

The assistant can always be asked “What can I do next?” It should inspect only
the current teacher's project state and suggest the smallest useful next step.
