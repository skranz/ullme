# AI Tutors and Skills

AI Tutors are student-facing teaching configurations. A course can install and
enable one or more Tutors. Definitions resolve from course-local, personal,
general, and package sources, with the more specific source taking precedence.

Skills are reusable instruction sets for the teacher assistant. A Skill can
provide a focused workflow, starter prompts, and composer guidance. Activating
a Skill affects the current teacher conversation but does not bypass approval,
validation, or authorization rules.

Use the Definitions workspace to inspect the underlying YAML and Markdown,
create editable copies, import or download definitions, and ask the Definition
Assistant for a reviewable draft.
